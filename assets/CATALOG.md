# Asset catalog

Generated by `python -I tools/assets/catalog.py` (do not edit by hand). Paths are relative to `assets/`.
Sizes are X x Y x Z in meters from `tools/assets/bounds.py` (glTF accessor bounds with node transforms).

Conventions:

- +Y up. Kenney and Quaternius models face +Z (Kenney boats: bow at +Z; Quaternius fish: head at +Z, checked by end taper). If game code treats -Z as forward, rotate the model by pi about Y.
- Kenney kits are toy-scale (survival floor tile = 0.5 m, raft tile = 2 m): the Notes give suggested scale factors. Kenney origins are at the bottom center unless a note says otherwise (nature kit: bottom at y = -0.05).
- Kenney GLBs use `Textures/colormap.png` next to them, one per kit folder. Do not move a GLB without its Textures folder.
- Skinned models (marked with a clip set) report bind-pose bounds; the armature transform is not applied, so Quaternius fish and monsters can render at a very different size. Check with `rusting capture` and scale to the target size.
- Rows with no path or a 'Fallback' note have no good asset: use the suggested engine primitive.
