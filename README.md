# Rusting Raft

Survive on a small raft on the open ocean, alone or with up to 7 friends. Fish, sell the
catch to Barnaby on Hook Isle, shred floating debris into wood and metal, grow the raft, feed
the campfire through five levels, build farms, rescue survivors by radio and sail out to
harder islands. Days last 5 minutes, nights 1 minute: stay near the fire after dark.

Built with [RustingEngine](https://github.com/GoingRusting/RustingEngine) 2.3.0. A full run
takes 1 to 2 hours.

## Play

The engine must be checked out next to this folder (`../RustingEngine`).

```powershell
rusting run C:\Users\juliu\RustingRaft --release            # play
rusting export C:\Users\juliu\RustingRaft C:\Users\juliu\Games   # standalone build to share
```

On Linux, build the export on a Linux machine (`rusting export . ~/games`).

| Ctrl | Dive |
| Mouse | Look |

| B | Build menu (near the workbench) |
| R | Rotate the build ghost |
| Tab | Sac (inventory) |
| V | First / third person |
| Esc | Pause, settings |

### How it goes

1. Fish with the rod (left mouse to cast, click when the marker is in the zone to reel in).
2. Swim to Hook Isle (about 8 s) and sell the fish to Barnaby. He sells better gear and
   gives the first jobs.
3. Harpoon or pick up debris and feed it to the shredder for wood and metal. Enemy bodies
   give biomass.
4. Feed the campfire: every 25 wood (oil counts more) raises its level and unlocks recipes.
   Level 3 unlocks wood, metal and oil farms; level 4 the radio.
5. The radio finds survivors on far islands. Rescued survivors run your farms, feed the
   shredder and pour oil into the fire.
6. Boats reach the far islands, their quests and chests. A wandering trader docks every
   other day.
7. If the fire goes out at night, creatures climb aboard. A downed player waits for a
   friend to revive them; if everyone is down, the game is over.

Saving is done by the host from the Logbook and costs coins (150 + 75 x campfire level).

## Multiplayer

One player hosts, the others join with a room code. Everyone connects through a small relay
server, for example on a Linux home server: see [docs/relay.md](docs/relay.md) for building,
the hardened systemd unit (`deploy/rusting-relay.service`), port forwarding and what it
defends against.

- Host: main menu, *Host online*, relay address (such as `myhome.example.net:27777`). Send
  the room code to your friends.
- Join: *Join online*, the same relay address, the code and a name.

Only the host's PC runs the world and writes the save. Each install keeps a private token,
so nobody else can take over your player in a world.

## Development

| Path | What |
| --- | --- |
| `sim/` | `raft_sim`: every game rule, deterministic, with a full progression test |
| `net/` | `raft_net`: host / client sessions over the relay |
| `relay/` | `raft-relay` server (std only) |
| `src/` | the client: `view/` (world visuals), `ui/` (menus, HUD), `player/` (controls) |
| `scenes/main.rscene` | the world, generated by `tools/scene/build_scene.py` |
| `tests/` | engine scenarios (`rusting test`) |

```powershell
rusting check C:\Users\juliu\RustingRaft
rusting test C:\Users\juliu\RustingRaft
cargo test --workspace
```

`docs/CLIENT_CONTRACT.md` describes how the client modules fit together, and
`docs/superpowers/specs/2026-10-09-rusting-raft-design.md` the full game design. Asset
credits are in `assets/CREDITS.md`. `missingFeatures.md` lists what the game needed from
the engine and wrote itself for now.
